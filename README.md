# 塾の時間割メーカー

**すぐ使う：https://ryohei-yoshida-cpu.github.io/juku/** （ログイン不要。GitHub Pages で公開）

中学生向け個別指導塾の月間時間割を作るWebアプリです。インストール不要で、`index.html` をブラウザで開くだけで使えます。データはブラウザ内（localStorage）に自動保存されます。

## 使い方

1. **設定**：時限（コマ）の時間、開校曜日、講師1人が1コマで見る人数、生徒1日の上限コマ数、1教科の月の標準回数（初期値4回）、塾独自の休み（お盆・年末年始など）を決めます。祝日（振替休日・国民の休日を含む）は自動で休みになります。
2. **講師**：名前・担当教科（国語・数学・英語・理科・社会）・出勤できる曜日と時限・休みの日を登録します。
3. **生徒**：名前・学年・コース（3科目＝英数国／5科目＝英数国理社）・教科ごとの月の回数・来られる曜日と時限・来られない日・**NG講師**（期間と理由。期間を空欄にすると無期限）を登録します。
4. **① 講師シフト**：講師の登録内容と祝日から、その月の出勤コマが自動で作られます。マスをクリックして ○ を付け外しし、先に講師のスケジュールを確定させます。
5. **② 時間割**：「自動で埋める」で、講師シフトの中に生徒を入れていきます。
   - 生徒の来られる日時、NG講師の期間、担当教科、講師の定員、1日の上限、同じ日に同じ教科を入れないことを守ります。
   - なるべく月の中で均等に散らし、同じ教科は同じ講師が続けて担当するようにします。
6. **手動修正**：「日別」画面で授業をドラッグ＆ドロップして移動したり、クリックして生徒・教科・日時・講師を変更・削除したりできます。マスの「＋」で追加もできます。
   - ルールに合わない授業は赤枠の ⚠ で表示され、「不足・警告」画面にまとめて出ます。
   - 手で直した授業には 🔒 が付き、自動作成をやり直しても残せます。
   - 授業の編集画面には、その生徒・教科を入れられる空き枠の候補が出ます。

「生徒別」「講師別」の一覧、印刷、CSV出力（Excel対応）、JSONでのバックアップ・読み込みもできます。「データ」タブからサンプル（講師6名・生徒14名）を読み込んで試せます。

## ファイル構成

- `index.html` / `css/style.css` / `js/app.js`：画面
- `js/scheduler.js`：自動作成・チェックのロジック
- `js/holidays.js`：日本の祝日計算
- `js/sample.js`：サンプルデータ
- `tests/test.js`：テスト（`node tests/test.js`）

## Webページとして公開する

`node tools/build-artifact.js 出力先.html` で、CSS・JSを1つにまとめたHTMLを作れます。
埋め込み表示でも動くように、確認はブラウザのポップアップではなく画面内のダイアログで行い、書き出しは「コピー」でできるようにしています。
